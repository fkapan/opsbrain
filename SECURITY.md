# Security reports

Please do not report security-sensitive details in a public GitHub Issue.

Before publishing, replace the contact placeholder below with a private maintainer address or enable GitHub Security Advisories for the distribution repository:

`[PRIVATE_SECURITY_CONTACT]`

Do not send customer logs, passwords, tokens, private keys, kubeconfigs or connection strings. Redact all operational data before sharing a reproduction.

OpsBrain is local-first and does not provide live infrastructure access. A report should include the application version, Windows version, runtime mode and safe reproduction steps whenever possible.
